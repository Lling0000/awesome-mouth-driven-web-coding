# Contributing

Thanks for helping improve **口喷式 Web Coding 的教学**.

## What We Welcome

- New mouth-driven coding lessons for Codex, Cos, Claude Code, Cursor, AI IDEs, terminals, or web coding workflows.
- Better bilingual wording.
- Real screenshots that clarify a step.
- Prompt recipes with before/after results.
- Lexicon extraction rules, import adapters, and daily dictionary workflows.
- Broken link fixes.
- Carefully selected additions to `AWESOME.md`.

## Quality Bar

Every contribution should be:

- Reproducible: someone else can follow it with right `Command` voice input and an AI execution surface.
- Screenshot-backed when it describes UI or installation.
- Beginner-readable without hiding important details.
- Bilingual when it changes core docs.
- Honest about limitations and required permissions.

## Resource List Rules

For `AWESOME.md`, each item must include:

```md
- [Name](https://example.com/) - Why this is useful for voice-first web coding.
```

Do not add:

- Pure ads.
- Affiliate-only links.
- Tools you have not opened or verified.
- Huge AI-generated batches of links.
- Resources unrelated to web building, voice input, design, debugging, or shipping.

## Lexicon Contribution Rules

For Qianwen lexicon additions:

- Prefer stable product names, project names, APIs, tools, abbreviations, and domain terms.
- Avoid private customer names unless the repo is private.
- Include the source context when proposing extraction-rule changes.
- Keep generated lexicons reviewable as text and JSON.

## Screenshot Rules

- Remove or crop private information.
- Show the actual state described in the step.
- Prefer PNG for UI screenshots.
- Use clear filenames such as `05-microphone-permission.png`.

## Commit Style

Short, plain commits are best:

```text
docs: add English install guide
assets: add Qianwen permission screenshot
awesome: add deployment resources
```
